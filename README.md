# C++ Systems Programming

A hands-on collection of **C++ concepts, systems programming
fundamentals, and low-level programming experiments**, developed from
the ground up.

This repository documents my learning journey as I build a strong
foundation in C++ and explore how software interacts with memory,
processors, operating systems, and hardware. It will also serve as a
reference for concepts relevant to **CUDA development, GPU computing,
and AI infrastructure**.

## Learning Areas

The repository will grow topic by topic as concepts are studied and
implemented.

### C++ Fundamentals

-   Variables, data types, and type conversions
-   Operators and control flow
-   Functions and scope
-   Arrays and strings

### Pointers and References

-   Pointers and memory addresses
-   Pointer arithmetic
-   Pointers to pointers
-   References and their use cases

### Core C++

-   Object-oriented programming
-   Classes, objects, and constructors
-   Standard Template Library (STL)
-   Templates and modern C++

### Memory Management

-   Stack and heap
-   Dynamic memory allocation
-   Object lifetime and ownership
-   RAII and smart pointers

### Data Structures and Algorithms

-   Common data structures implemented in C++
-   Searching and sorting
-   Algorithmic problem solving

### Systems Programming

-   Compilation and linking
-   Processes and operating-system interactions
-   File handling and I/O
-   Low-level programming concepts

### Concurrency and Performance

-   Threads and synchronization
-   Mutexes and atomics
-   Parallel programming fundamentals
-   Profiling and performance optimization

### GPU and CUDA Programming

-   GPU architecture fundamentals
-   CUDA programming model
-   Kernels, threads, and blocks
-   Host and device memory
-   Parallel execution and optimization

## Approach

-   **Learn the fundamentals:** Understand each concept before moving to
    advanced applications.
-   **Implement from scratch:** Write small programs and experiments to
    reinforce understanding.
-   **Explore memory and execution:** Pay attention to object lifetime,
    memory layout, and program behavior.
-   **Document key ideas:** Keep useful explanations, examples, and
    observations alongside the code.
-   **Build progressively:** Connect C++ fundamentals to systems
    programming and GPU computing.

## Goals

-   Develop a strong and practical understanding of C++.
-   Understand memory, resource management, and program execution.
-   Build familiarity with systems-level programming concepts.
-   Develop the foundations needed for CUDA and GPU programming.
-   Maintain a clear, reusable reference for future projects and
    technical interviews.
